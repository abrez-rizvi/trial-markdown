# Ever-Brain Testing Guide

This document is created to test Ever-Brain synchronization workflows:
1. evb diff: Inspect local vs remote changes.
2. evb push: Direct commit to the repository (maintainers).
3. evb propose: Propose changes via Pull Request (contributors).

## Sample Runbook
- Step 1: Modify cache docs.
- Step 2: Validate with evb diff.
- Step 3: Publish changes.
- Step 4: Testing
